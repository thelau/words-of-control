# Simulated visitors — a held-out test set

What people are likely to type into the piece in a gallery, written to test how well the reference words
(docs/reference-words.md) match it: how close their nearest reference words are, and whether those make sense.
**Invented, not collected** (visitors' words are never stored). **Held out**: none of these entries may be copied into
the reference list, or the test would only measure itself. Recorded and scored by `node scripts/simulate.ts`.
